# MarkText 0.23.0 安装说明

## 这是什么

一个**开箱即用**的 Markdown 编辑器：不需要联网、不需要 Node.js / Python / 任何开发环境。
提供两种形态：

| 产物 | 适用 |
| --- | --- |
| `MarkText-0.23.0-安装程序.exe`（119.6 MB） | 平时用：桌面/开始菜单/右键新建都就绪 |
| `MarkText-0.23.0-便携版.exe`（119.5 MB） | 不想装、放 U 盘、公用电脑：自解压到任意文件夹，不写注册表 |

两者解出来都是同一个应用：**106 个文件 / 481.6 MB**（已去掉 11 个用不到的语言包，只留中文/英文）。

## 安装版

| 项目 | 说明 |
| --- | --- |
| 文件名 | `MarkText-0.23.0-安装程序.exe` |
| 大小 | 119.6 MB（125,361,374 字节；装后 481.6 MB / 106 文件） |
| SHA256 | `64c6e15aefe2728525c217e2a4781a47e62a6f91eeef292fcc8ea698e6108c49` |
| 管理员权限 | **不需要**，默认 `%LOCALAPPDATA%\Programs\MarkText`，可自选目录 |
| 支持系统 | Windows 10 / 11（64 位） |

### 安装步骤

1. 双击 `MarkText-0.23.0-安装程序.exe`
2. 若弹「Windows 已保护你的电脑」→ **更多信息 → 仍要运行**（个人打包、未签名）
3. **下一步** → 选目录 → **安装** → 勾「立即打开」→ 完成
4. 第一次打开自动弹《新手教学》

### 装完之后

| 位置 | 内容 |
| --- | --- |
| 桌面 | `MarkText` 快捷方式 |
| 开始菜单 | MarkText / 新手教程 / 卸载 MarkText |
| **右键 →「新建」** | **Markdown 文档** |
| 右键 `.md` →「打开方式」 | MarkText（**只有一项**） |
| 程序目录 | `教程\`（新手教学 + 使用说明 + 4 张配图） |

## 便携版

| 项目 | 说明 |
| --- | --- |
| 文件名 | `MarkText-0.23.0-便携版.exe` |
| 大小 | 119.5 MB（125,339,454 字节；解出后 481.6 MB） |
| SHA256 | `61d6a5d8cef1d61a45de78b996735749f1e6567c499c68f96591122dd70f8519` |

1. 双击，选一个空文件夹（U 盘也行）→ 解压
2. 双击里面的 `启动 MarkText 便携版.exe`

配置与缓存都在该文件夹 `data\`，整个文件夹拷走即可；想清空设置就删 `data\`。
便携版**不会**接管 `.md` 默认打开方式（公用电脑上这是好事）。

## 相比官方包的改动

| 改动 | 原因 |
| --- | --- |
| 表格里按 **Enter** 直接插入新行 | 官方是 Enter 跳格、`Ctrl+Enter` 才插行；改成 Word 习惯 |
| 移除自动更新（删 `app-update.yml`） | 防止自动升级把上面的改动覆盖掉 |
| 首次启动自动打开新手教程 | 由 `启动 MarkText.exe` 负责，只弹一次 |
| **右键新建 Markdown 文档** | 和 Office 一样的习惯 |
| `.md` 只登记一个 ProgId | 旧版同时写两个，会让「打开方式」出现 3 个 MarkText |
| **精简体积** | 只留 `zh-CN` / `en-US` 语言包（省 7.7 MB）；便携版改自解压（179 → 119.5 MB） |

## 两个常用功能怎么用

**导出 / 打印成 PDF**：`文件 → 导出 → PDF`，可设纸张（A4）、页边距、页眉页脚、书签。
中文用系统字体（微软雅黑/宋体）最稳；宽表格放不下就改横向或拆表。

**插入图片（像 Word）**：拖进来 / `Ctrl+V` 粘贴截图 / `插入 → 图片` / 输入 `/` 选「图片」。
点图片出现工具栏可调大小与对齐。**防丢图**：`设置 → 图片` 把「插入图片后的动作」改成
**复制到文件夹**，并勾选**优先使用相对路径**。

## 卸载

开始菜单 → MarkText → **卸载 MarkText**；或 设置 → 应用 → MarkText 0.23.0 → 卸载。
只删程序目录和快捷方式，**不动你的 Markdown 文档**；配置留在 `%APPDATA%\marktext`，要彻底清理可手删。

## 重新打包

工程：`…\default-workspace\MarkText中文定制版-源码\工程\`

```powershell
powershell -ExecutionPolicy Bypass -File 工程\build\build.ps1             # 只打安装包
powershell -ExecutionPolicy Bypass -File 工程\build\build.ps1 -Portable   # 安装包 + 便携版
```

可选：`-AppSrc` / `-Tutorial` / `-KeepAllLocales`（保留全部语言包）/ `-KeepStage`。

## 已知限制
