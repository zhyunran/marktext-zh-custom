# MarkText 0.23.0 安装说明

## 这是什么

一个**开箱即用**的 Markdown 编辑器：不需要联网、不需要 Node.js / Python / 任何开发环境，装完就能用。
提供两种形态：

| 产物 | 适用 |
| --- | --- |
| `MarkText-0.23.0-安装程序.exe` | 平时用，装好后桌面/开始菜单/右键新建都就绪 |
| `MarkText-0.23.0-便携版.zip` | 不想装、放 U 盘、公用电脑：解压即用，不写注册表 |

## 安装版

| 项目 | 说明 |
| --- | --- |
| 文件名 | `MarkText-0.23.0-安装程序.exe` |
| 大小 | 121.0 MB（126,886,549 字节；装后约 489 MB / 116 文件） |
| SHA256 | `8f6054caad39bc8d188258ef794a7a2327288a7e89061cd9ff3659c50ece7946` |
| 管理员权限 | **不需要**，默认装到 `%LOCALAPPDATA%\Programs\MarkText`，可自选目录 |
| 支持系统 | Windows 10 / 11（64 位） |

### 安装步骤

1. 双击 `MarkText-0.23.0-安装程序.exe`
2. 若弹「Windows 已保护你的电脑」→ **更多信息 → 仍要运行**（个人打包、未签名，属正常）
3. **下一步** → 选目录 → **安装** → 勾选「立即打开」→ 完成
4. 第一次打开自动弹《新手教学》

### 装完之后多出来的东西

| 位置 | 内容 |
| --- | --- |
| 桌面 | `MarkText` 快捷方式 |
| 开始菜单 | MarkText / 新手教程 / 卸载 MarkText |
| **右键 →「新建」** | **Markdown 文档**（空 .md，双击即开） |
| 右键 `.md` →「打开方式」 | MarkText（**只有一项**） |
| 程序目录 | `教程\`（新手教学 + 使用说明 + 4 张配图） |

## 便携版

| 项目 | 说明 |
| --- | --- |
| 文件名 | `MarkText-0.23.0-便携版.zip` |
| 大小 | 179.4 MB（188,158,801 字节；解压后约 489 MB） |
| SHA256 | `c9f50cdb339a7f41807482b17ea9de8c6056c50957666fc10c3b9c91b773ba3a` |

1. 解压到任意位置（U 盘、D 盘都行）
2. 双击 `启动 MarkText 便携版.exe`
3. 不安装、不要管理员、不写注册表、不建快捷方式

配置与缓存都在同目录 `data\`，整个文件夹拷走即可；想清空设置就删 `data\`。
便携版**不会**接管 `.md` 默认打开方式（公用电脑上这是好事）。

## 相比官方包的改动

| 改动 | 原因 |
| --- | --- |
| 表格里按 **Enter** 直接插入新行 | 官方是 Enter 跳格、`Ctrl+Enter` 才插行；改成 Word 习惯 |
| 移除自动更新（删 `app-update.yml`） | 防止自动升级把上面的改动覆盖掉 |
| 首次启动自动打开新手教程 | 由 `启动 MarkText.exe` 负责，只弹一次 |
| **右键新建 Markdown 文档** | 和 Office 一样的习惯 |
| `.md` 只登记一个 ProgId | 旧版同时写 `MarkText.Document` 和 `Applications\marktext.exe`，会让「打开方式」出现 3 个 MarkText |
| 自带中文教程 | 方便离线发给不熟悉 Markdown 的人 |

## 两个常用功能怎么用

**导出 / 打印成 PDF**：`文件 → 导出 → PDF`，可设纸张（A4）、页边距、页眉页脚、书签。
中文用系统字体（微软雅黑/宋体）最稳；宽表格放不下就改横向或拆表。

**插入图片（像 Word）**：拖进来 / `Ctrl+V` 粘贴截图 / `插入 → 图片` / 输入 `/` 选「图片」。
点图片出现工具栏可调大小与对齐。
**防丢图**：`设置 → 图片` 把「插入图片后的动作」改成**复制到文件夹**，并勾选**优先使用相对路径**。

## 卸载

开始菜单 → MarkText → **卸载 MarkText**；或 设置 → 应用 → MarkText 0.23.0 → 卸载。

只删程序目录和快捷方式，**不动你的 Markdown 文档**；用户配置留在 `%APPDATA%\marktext`，要彻底清理可手删。

## 重新打包

工程：`…\default-workspace\MarkText中文定制版-源码\工程\`

```powershell
powershell -ExecutionPolicy Bypass -File 工程\build\build.ps1            # 只打安装包
powershell -ExecutionPolicy Bypass -File 工程\build\build.ps1 -Portable  # 安装包 + 便携版 zip
```

可选参数：`-AppSrc`（已装 MarkText 目录）、`-Tutorial`（教程目录，默认整份教程）、`-KeepStage`（保留暂存区）。
打完后把 `dist\` 里的产物复制到公共成品目录覆盖旧件。

## 已知限制

- **未做代码签名**，首次运行会有 SmartScreen 提示。
- 图标与界面沿用官方 MarkText，未改品牌标识。
- 与官方版可共存（装在不同目录），但 `.md` 的「打开方式」只指向最后安装的那个。
