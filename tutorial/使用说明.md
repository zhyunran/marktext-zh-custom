# MarkText 使用说明（已按你的需求调好）

这是在「展示页」直接编辑的所见即所得编辑器：加粗显示成**加粗**、表格显示成真表格，
不用对着 `**`、`|` 写代码。（下面的文字就是效果本身。）

## 一、基础编辑

- 想加粗：选中文字按 `Ctrl + B`；想斜体：`Ctrl + I`
- 光标移到某段加粗文字里时，前后会短暂露出淡灰的 `**`（提示你这段是加粗语法），
  移开光标就消失 —— 这段灰色标记只能提示语法，不影响你直接删改文字
- 想看纯 Markdown 源码：`Ctrl + E` 切换

## 二、新建 / 打开 / 导出

| 要做的事 | 怎么做 |
| --- | --- |
| **新建 Markdown 文档** | 桌面或文件夹里 **右键 → 新建 → Markdown 文档**（装完就有） |
| 打开已有文件 | 把 `.md` 拖进窗口，或 `文件 → 打开` |
| **导出成 PDF（打印）** | `文件 → 导出 → PDF`，可设纸张、页边距、页眉页脚、书签 |
| 导出成 HTML | `文件 → 导出 → HTML`，方便网页发布 |

> 导出 PDF 用的是系统字体，中文用微软雅黑/宋体最稳；用了自己下的字体，换电脑可能变方块。
> 宽表格在 A4 竖排放不下时，改成横向或拆表。

## 三、插入图片（像 Word 一样）

| 方式 | 怎么做 |
| --- | --- |
| 拖进来 | 把图片文件拖到光标处 |
| 粘贴 | 截图后 `Ctrl + V` |
| 菜单 | `插入 → 图片` |
| 打命令 | 输入 `/` → 选「图片」 |

插进去后**点一下图片**会出现工具栏：拖动小方块调大小、切换左/中/右对齐。

> **防丢图**：默认插的是原图路径，文档发给别人图就没了。
> 到 `设置 → 图片` 把「插入图片后的动作」改成**复制到文件夹**，并勾选**优先使用相对路径**。
> 之后图片会被复制到指定目录、文档里写相对路径，整个文件夹拷走即可。

## 四、表格（重点）

| 操作 | 怎么做 |
| --- | --- |
| 新建表格 | 空行输入 `/` → 选「表格」→ 在弹出的网格里点格子；或直接在 `0 × 0` 那里填行数×列数 → 点 **OK** |
| 快捷键新建 | `Shift + Ctrl + T` |
| **新增一行** | 单元格里按 **Enter**（已给你改成这个行为） |
| 单元格内换行 | `Shift + Enter` |
| 跳到下一格 | `Tab` / `Shift + Tab` |
| 上下移动 | 方向键 ↑ ↓ |

> 说明：MarkText 原版里 Enter 是「跳到下一行单元格」，`Ctrl + Enter` 才是插新行。
> 我把 Enter 直接改成了「在当前行下面插一行」，和你说的 Word 习惯一致。
> 原始文件已备份为 `app.asar.bak`，想还原随时说。

## 五、常用快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl + S` | 保存 |
| `Ctrl + E` | 所见即所得 / 源码模式切换 |
| `Ctrl + 1 ~ 6` | 一级~六级标题 |
| `Ctrl + 0` | 变回普通段落 |
| `/` | 插入任意块（标题、表格、代码块、公式、流程图…） |
| `Shift + Ctrl + T` | 插入表格 |
| `Alt + Ctrl + C` | 插入代码块 |
| `Alt + Ctrl + Q` | 插入引用 |

## 六、其他

- 只读浏览：菜单 `查看 → 阅读模式`
- 左侧文件树：`查看 → 显示侧边栏`
- **便携版**：解压后双击 `启动 MarkText 便携版.exe`，配置在 `data\`，整个文件夹可拷走
